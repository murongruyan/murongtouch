# 慕容触控采样率

按前台应用自动切换触控采样率的 KernelSU / Magisk 模块（**付费授权模块**）。

免费安装后，按以下流程购买并启用：

1. 打开模块 WebUI → 用户页 → 登录 / 注册账号；
2. 购买授权（**3 元 · 单机永久**，支付页付款）；
3. 支付成功后服务端自动发放卡密并绑定你的设备（也可手动输入卡密激活）；
4. 在用户页点「下载付费组件」，安装守护进程；
5. 服务端会为你的设备签发 **3 天有效的 Ed25519 授权租约**（自动续期，含 3 天离线宽限）；
6. 守护进程校验签名/有效期/设备绑定，通过后自动切换采样率。

> 免费模块本身不含守护进程二进制，未购买/未安装组件时 WebUI 可正常打开但不会切换采样率。
> 支持机型：真我 GT8 Pro（RMX5200，ColorOS 17）实测通过；ColorOS 17 多机型自动探测，
> ColorOS 12~16 走 legacy 通道（需按机型配置）。

## 功能

- **自动切换**：白名单应用前台 → 下采样率；退出 → 恢复进入前原值；看门狗防官方覆盖。
- **全局 + 每应用自定义**：`config/采样率.txt`，第一行全局 Hz，其余 `包名 采样率`；改完 1~2 秒热生效。
- **档位**：120 / 180 / 240 / 288 / 360Hz；**隐藏档 400Hz**（实测约 385~400Hz，非官方，谨慎使用）；
  16 及以上 code 会让触控停止报点，界面已禁止。
- **KSU WebUI**（四页）：
  - **主页**：当前采样率、读取当前档位、真实报点率测试、前台/命中/后端状态、卸载模块；
  - **配置**：全局采样率平铺 + 自动检测已安装应用、逐应用设档（已配置应用置顶、可搜索，改完立即生效）；
  - **日志**：一键收集诊断信息打包分享；
  - **用户**：账号登录/注册、购买授权、卡密激活、租约状态与续租、下载付费组件、我的卡密/订单、外观设置。
- **外观**：用户页 → 外观设置 → 主题界面：背景颜色（白/黑/跟随系统/自定义）、主题模式、强调色、文字颜色、恢复默认。
- **多机型自动探测**：hbp / proc_rate / white_list / legacy 四种后端。

## 安装

1. KernelSU / Magisk 管理器 → 模块 → 从本地安装 → 选择 `慕容触控采样率-v5.0.zip`；
2. 重启手机；
3. 打开模块 WebUI → 用户页完成登录/购买/下载付费组件；
4. 安装组件后会自动启动守护进程（也可在用户页点「重启守护进程」）。

## 配置（config/采样率.txt）

```text
# 第一行 = 全局采样率（0=不强制/恢复系统原值；120/180/240/288/360/400）
180
# 其余行 = 包名 采样率
com.tencent.tmgp.sgame 360
com.miHoYo.Yuanshen 240
```

语义：命中规则 → 用规则值；未命中且全局>0 → 全局值；否则恢复系统原值。

## 授权与租约

- 3 元买断、一码一机、永久授权；换机请联系作者（每码限一次免费换绑）。
- 授权文件为服务端签名的 Ed25519 租约，**3 天有效 + 3 天离线宽限**，WebUI 打开时自动续租；
  宽限过期且无法联网续租时，守护进程会恢复系统原采样率并停止写入（联网后可自动恢复）。
- 激活信息保存在模块 `config/auth/`，重装模块需重新登录/激活。

## 日志与反馈

WebUI → 日志 → **一键收集诊断信息**：打包守护进程日志、状态、机型/系统、采样率配置等
到 `Download/慕容触控采样率_diag_*.zip`，点「分享」发给作者，不需要自己看日志。

## 兼容与排查

| 现象 | 处理 |
| --- | --- |
| 主页提示「未安装付费组件」 | 用户页登录购买后点「下载付费组件」 |
| 主页提示「授权过期/未授权」 | 用户页点「续租」/重新激活卡密；检查网络 |
| 后端显示「无可用后端」 | 日志页收集诊断包发作者（新机型可能需要适配） |
| 档位被官方改回 | 官方 touchDaemon 切场景瞬间会写一次，看门狗自动抢回（约 1~2 秒） |
| ColorOS 12~16 旧机型 | 在 `config/legacy.conf` 按机型填写 touchHidlTest 命令后启用 |

## 卸载

模块管理器内卸载即可：停止守护进程、恢复系统采样率、还原设置。
手动作业：`touch /data/adb/modules/gt8pro_touch/remove` 后重启。
